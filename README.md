# SkySearch — 机票搜索

基于 React + Vite + Express 构建的中文机票搜索网站，支持国内、国际航班，含城市选择器。

## 部署到 Vercel

### 第一步：上传到 GitHub（iPad 用 Working Copy App）
1. App Store 安装 **Working Copy**（免费）
2. 登录 GitHub 账号 → 新建仓库 `skysearch`
3. 解压本文件夹，通过 Working Copy 全部提交上传

### 第二步：Vercel 部署
1. 打开 vercel.com，用 GitHub 登录
2. Import 仓库 → Output Directory 填 `dist/public`
3. 点 Deploy，2分钟后上线

### 无需配置任何环境变量、数据库或 API Key
